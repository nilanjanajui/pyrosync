# PyroSync — Agent Operational Guidelines

## Non-Negotiable Rules
1. **Never fabricate data or statistics**: Real data comes only from `frontend/public/datasets/`. Synthetic data is generated by `backend` (`synth` command) and carries `"synthetic": true`, which shows a persistent red "SYNTHETIC DATA" banner.
2. **Harmonization labeling**: A harmonized number is always shown with its method label: active mode, `status` (provisional or validated), `method`, `version`, and which months are native vs scaled/modeled.
3. **Detection record semantics**: A detection record is not a unique fire. Zero means "no detection record", not proof of no fire. A month before a sensor operated is "no data" (null), never zero. 2012-01 is a partial VIIRS month and is marked as such.
4. **No secrets or tracking**: No analytics, tracking or paid services. No secrets in the repo. A FIRMS MAP_KEY, if ever used, exists only as a server environment variable.
5. **Reconciliation invariant**: Counts and hotspot rows must reconcile: for any AOI and date range, the number of hotspot rows per sensor equals the sum of that sensor's counts in the monthly series. This is strictly tested.
6. **Accessibility**: WCAG 2.2 AA is a hard requirement. Colorblind-safe palettes, full keyboard navigation, aria-grid on calendar, skip links, aria-live updates.
7. **Approved stack**: Use only the approved stack. Verify package names and versions before installing. Ask before adding dependencies.
8. **Never guess**: If ambiguity or conflict with real data arises, stop and ask.
9. **Naming rules**: No directory anywhere may be named `data` (the root `.gitignore` ignores `/data/`). Use `datasource`, `datasets`, `store`.
10. **Notebooks**: Never modify `notebooks/`.

## Build and Test Commands

### Backend (`backend/`)
```bash
# Setup virtual environment and dependencies
cd backend
python3 -m venv .venv
source .venv/bin/activate
pip install -e .
pip install -r requirements-dev.txt

# Lint and format
ruff check pyrosync/ tests/
ruff format --check pyrosync/ tests/

# Unit tests
pytest

# CLI commands
python -m pyrosync.cli synth --out ../frontend/public/datasets
python -m pyrosync.cli check --data ../frontend/public/datasets
```

### Frontend (`frontend/`)
```bash
cd frontend

# Install dependencies
npm ci

# Linting and Typechecking
npm run lint
npm run typecheck

# Unit tests
npm test

# Production build
npm run build

# End-to-End tests (Playwright)
npm run test:e2e
```
